# Motion language

Treat these as interpretation cues, not fixed templates. Combine only what the composition needs and report subjective choices.

## Spatial phrases

- “spread out / line up / march”: linear generator; use direction in start/end.
- “orbit / halo / radiate”: radial generator; `pathProgress` or rotation can imply circulation.
- “field / constellation / organic distribution”: seeded scatter with generous bounds.
- “grid / system / orderly”: grid generator with consistent gaps.
- “along the edge/path”: path generator using a line, circle, or four-point polygon.
- “toward / away from”: attract or repel; keep strength bounded.
- “follow / chase”: follow, optionally lookAt as supporting motion.

## Rhythm and force

- “breathe / pulse / gentle”: sine wave, low amplitude and frequency.
- “mechanical / stepped”: triangle or saw wave with restrained amplitude.
- “ripple / one after another”: wave plus index, linear, radial, or time falloff.
- “random / alive / imperfect”: seeded noise or random falloff; never change seeds casually.
- “snappy”: spring with higher stiffness and adequate damping.
- “soft / floaty”: lower-frequency wave or noise; avoid stacking both without a reason.
- “magnetic”: attract; “shy / clears away”: repel.

## Typography

- “letters dance”: text split into `characters`, one primary binding, and restrained rotation/position.
- “words arrive in sequence”: `words` split with index or time falloff.
- “editorial”: strong static hierarchy; motion supports reading rather than competing.
- “kinetic”: one legible dominant text behavior, with limited supporting motion.

## Subjective direction

Translate “calmer” by reducing amplitude, frequency, strength, and behavior count before changing the composition. Translate “more energetic” with a modest increase in one dominant variable. “Playful” can use phase/index variation and friendly geometry; “premium” favors fewer elements, slower motion, and disciplined spacing; “chaotic” still needs a focal point and bounded counts.

If “make it better,” “more dynamic,” or similar wording has several materially different meanings, prefer the smallest reversible adjustment supported by the current scene. If none is defensible, ask one focused question such as: “Should ‘more dynamic’ mean faster movement or a larger movement range?”

For unsupported 3D, approximate depth with scale, opacity, overlap, and radial/linear spacing. For images, approximate with geometric silhouettes only when that preserves the intent. For audio-reactive requests, offer a deterministic rhythmic wave. Never imply true export, image import, audio sync, timeline editing, or code execution.
